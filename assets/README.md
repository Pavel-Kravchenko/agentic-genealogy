# Graphics

The logo and the diagrams used in the main README. Each is drawn in light ink on its own dark panel, so it
reads the same on a light and on a dark page. `social-preview.png`
is the image for the repository's social preview.

The lettering is set in Instrument Serif and Inter, both published under the SIL Open Font License 1.1, and
converted to outlines. The graphics are original work for this repository and are
licensed like the text, under Creative Commons Attribution 4.0 (see `LICENSE-docs` in the repository root).
