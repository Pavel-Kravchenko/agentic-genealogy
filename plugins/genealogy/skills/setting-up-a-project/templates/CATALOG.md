# Catalogue

What lies where and why. One-line rule: only the graph (by script), the transcriptions, the documents
for the family and the ledgers are edited; everything else is generated, an archive, or raw material.

| folder | what is there | edited by hand? |
|---|---|---|
| `Graph/` | persons and links, snapshots | by script only |
| `Tree/` | viewer, GEDCOM, printable sheets | no, generated |
| `Sources/` | scans, copies, photos, audio, transcriptions, inventory | transcriptions only |
| `Reports/` | output of search sessions and agent waves | no, a record |
| `For-the-family/` | documents in plain language for relatives | yes |
| `Tools/` | scripts | yes, with self-checks |
| `Work/` | temporary | may be cleaned |
